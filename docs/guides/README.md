# ECS3D Guides

Short, practical guides for people who have the engine built and want to make something with it.

- [Getting started](getting-started.md): what ships in `bin/`, the launcher, a First-Person project, play and stop, and the controls.
- [Editor basics](editor-basics.md): the panels, the viewport, play and stop, undo, settings and saving.
- [Your first script](your-first-script.md): write a C# script for an object, expose fields and hot reload it.
- [Scene scripts and events](scene-scripts-and-events.md): scene-wide scripts, and events between scripts.
- [Starter scripts](starter-scripts.md): the 17 ready-made scripts, their fields, events and where the samples use them.
- [Multiplayer](multiplayer.md): host Coin Rush from the command line, share your address and join from other machines.
